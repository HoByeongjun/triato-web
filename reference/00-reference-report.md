## 3. 화이트 베이스 디자인 핵심 패턴 (레퍼런스에서 추출)

### 3.1 색상 체계
```
배경 기본:     #FFFFFF
배경 섹션교차:  #F9FAFB 또는 #F7F7F8
카드 배경:     #FFFFFF (border로 구분)
Border:       rgba(0,0,0,0.08) 또는 #E5E7EB
본문 텍스트:   #333D4B 또는 #30302E
제목 텍스트:   #191F28 또는 #141413
보조 텍스트:   #6B7684 또는 #9CA3AF
액센트:       #00C8E8 (TRIATO 시안)
```

### 3.2 타이포그래피
- 영문: Inter 또는 Geist
- 한글: Pretendard 또는 Noto Sans KR (토스는 자체 폰트)
- Display: 48-72px / weight 700 / line-height 1.1 / letter-spacing -0.03em
- H2: 32-36px / weight 600 / line-height 1.2
- Body: 16-18px / weight 400 / line-height 1.7
- `word-break: keep-all` 필수 (한글)

### 3.3 CTA 버튼
- Primary: 다크 배경(`#191F28` 또는 `#000`), 흰 텍스트, border-radius 8-12px
- Secondary: 투명 배경, 1px border, 같은 텍스트색
- 패딩: 12px 32px
- 히어로에 2개(Primary + Secondary) 배치가 표준

### 3.4 섹션 구성 순서 (B2B/외주사 표준)
1. 히어로 (헤드라인 + 서브텍스트 + CTA 2개)
2. 고객사/파트너 로고 (신뢰도)
3. 서비스 소개 (3-4개 카드)
4. How it works (3단계)
5. 포트폴리오/케이스 스터디
6. 고객 추천사 (testimonial)
7. CTA 섹션 (최종 전환)
8. 푸터

### 3.5 여백/그리드
- 최대 너비: 1200-1440px
- 섹션 상하 패딩: 120-160px (데스크톱), 60-80px (모바일)
- 카드 그리드: 3열, gap 24-32px
- 섹션 간 배경색 교차로 구분 (divider 없음)
